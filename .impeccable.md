## Design Context

### Users
College/community members planning and discovering local events. Primarily mobile users who want quick access to event details, RSVP, and calendar sync. They expect a fast, clean experience with zero friction.

### Brand Personality
Minimal, focused, intentional. The interface should feel calm and confident — like a well-made tool, not a social media feed.

### Aesthetic Direction
- **Visual tone**: Ultra-minimal, black and white with a single accent color
- **Typography**: Geist Sans — clean, modern, no serifs
- **Theme**: Light mode only
- **References**: Linear, Vercel, Raycast — functional minimalism
- **Anti-references**: Colorful gradients, playful illustrations, busy social feeds

### Design Principles
1. **Clarity over decoration** — Every element must earn its place. No visual noise.
2. **Content-first** — Text, dates, and actions are the hero. Chrome is invisible.
3. **Mobile-native** — Designed for thumbs first, mouse second.
4. **One accent** — A single accent color for interactive elements. Everything else is grayscale.
5. **Quiet confidence** — The UI should feel premium through restraint, not embellishment.
